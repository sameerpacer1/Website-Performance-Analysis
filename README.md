# 📊 Website Performance Analysis

## 📌 Project Description
This project analyzes website traffic and user engagement using **Python & Jupyter Notebook**.  
It explores sessions, engagement rate, and marketing channel performance with clear visualizations.

---

## 🚀 Features
- Trends in sessions and users over time  
- Channel-wise traffic and engagement comparison  
- Engaged vs Non-Engaged sessions analysis  
- Hourly traffic heatmap by channel  
- Correlation between sessions and engagement rate  

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

---

## 📂 Dataset
- Source: Website analytics data (sessions, users, engagement rate, channel group, hourly traffic)  
- Columns used: `Sessions`, `Users`, `Engagement Rate`, `Channel Group`, `DateHour`, `Hour`

---

## 📈 Visualizations
- Bar plots for channel performance  
- Heatmap for hourly traffic by channel  
- Line chart for engagement rate vs sessions over time  
- Comparative plots for engaged vs non-engaged sessions  

---

## 🔍 Analysis Questions
1. What patterns or trends can be observed in website sessions and users over time?  
2. Which marketing channel brought the highest number of users?  
3. Which channel has the highest average engagement time?  
4. How does engagement rate vary across traffic channels?  
5. Which channels drive more engaged sessions compared to non-engaged ones?  
6. At what hours of the day does each channel drive the most traffic?  
7. Is there a correlation between high traffic and high engagement rate over time?  

---

## 📊 Results & Insights
"Organic Search brought the most users", "Social Media had highest engagement time"
